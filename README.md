# Thrones of Combat

Initial browser-game boilerplate for **Thrones of Combat**.

## Stack

- React
- TypeScript
- Vite
- Phaser 4

React owns the surrounding web application. Phaser owns the real-time game loop and gameplay systems.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
